Impara Git viaggiando nel tempo

Questa guida accompagna ogni livello del gioco Oh My Git!: cosa succede, quale concetto di Git c'è dietro, come superarlo dal terminale e come verificare di averlo capito davvero.

Come usarla. Leggi la storia e gli obiettivi, prova da solo nel gioco. Se ti blocchi apri prima il suggerimento, poi la soluzione. Alla fine rispondi alla domanda di verifica senza guardare la risposta e segna il livello come completato: il segno resta salvato in questo browser.

Le soluzioni sono state provate una per una dentro il gioco, digitando i comandi nel suo terminale. Usare il terminale invece delle carte ti fa guadagnare il badge d'oro del livello.

Prima di iniziare

Come si legge lo schermo del gioco

Quadratino giallo: un commit, cioè una fotografia dei file in un certo momento.
Freccia: va dal commit genitore al commit successivo. La storia scorre da sinistra a destra.
Etichetta blu: un branch (o un tag), un nome che punta a un commit.
Il gufo-scoiattolo azzurro: HEAD, ti dice dove sei adesso nella storia.
Obiettivi a destra: rossi finché non li raggiungi, poi verdi. Quando sono tutti verdi compare Next level.
Icone dei file: bianco = file reale, aura blu = versione nell'index, ombra scura = versione nell'ultimo commit.
Sempre -m nei commitSenza -m "messaggio" Git apre un editor (nel gioco una finestra di testo). Con -m fai tutto in una riga.
Gli hash cambianoGli identificativi dei commit (es. a1b2c3d) sono diversi per ogni partita. Copia sempre quelli che vedi tu.
Tasto destro su un commitInserisce il suo hash nel terminale. Utile dopo aver scritto git checkout .
Frecce e TabFreccia su/giù richiama i comandi precedenti; Tab completa i nomi dei file.
ReloadSe pasticci, il pulsante Reload riporta il livello allo stato iniziale.
Messaggi in italianoIl terminale usa il Git vero del computer: se il sistema è in italiano, leggerai "Si è passati al branch…", "HEAD scollegato" e simili.

Il modello mentale. Quasi tutto Git si capisce con quattro "posti" in cui può trovarsi una versione di un file. I livelli dei capitoli index, remotes e shit-happens ti fanno muovere tra questi posti.

Nessun livello corrisponde alla ricerca.
