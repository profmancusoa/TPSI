Impara i branch di Git un grafo alla volta

Questa guida accompagna ogni livello di Learn Git Branching (learngitbranching.js.org): la situazione di partenza, l'obiettivo, il concetto di Git che c'è dietro, una soluzione commentata e una domanda per verificare di averlo capito davvero.

Come usarla. Leggi la situazione e l'obiettivo, guarda il grafo "prima e dopo" e prova da solo nel gioco. Se ti blocchi apri prima il suggerimento, poi la soluzione. Alla fine rispondi alla domanda di verifica senza guardare la risposta e segna il livello come completato: il segno resta salvato in questo browser.

Tutte le soluzioni sono state provate una per una nel gioco, digitando i comandi nel suo terminale. Usano il numero minimo di comandi: il gioco le giudica uguali o migliori della soluzione ufficiale.

Prima di iniziare

Come si legge lo schermo del gioco

Cerchio: un commit. I nomi C0, C1, C2… sostituiscono gli hash di Git. Un apice (C2') indica una copia fatta da rebase o cherry-pick.
Freccia: collega un commit al suo genitore. Nel gioco la storia scende dall'alto verso il basso, in questa guida va da sinistra a destra.
Etichetta: un branch. Nel gioco l'asterisco (main*) indica il branch su cui ti trovi.
HEAD da solo compare quando è scollegato, cioè punta direttamente a un commit. In questa guida l'etichetta del branch attivo ha un pallino.
Branch remoto: dove si trovava main sul remoto origin l'ultima volta che ci hai comunicato. Le etichette viola sono i tag.
Cerchi tratteggiati: il repository remoto, a destra nel gioco. I cerchi sbiaditi sono commit che nessun branch usa più.
Comandi del giocolevels apre il menu, level intro1 va a un livello, show goal mostra l'obiettivo, objective rilegge le istruzioni.
Hai sbagliato?undo annulla l'ultimo comando, reset riporta il livello all'inizio. Puoi provare senza paura.
Suggerimentihint mostra il suggerimento ufficiale del livello. show solution mostra la soluzione: usalo solo come ultima risorsa.
Conta i comandiA fine livello il gioco confronta il numero dei tuoi comandi con quello della soluzione ufficiale. Prova a eguagliarla.
Niente -mNel gioco git commit non chiede il messaggio. Nel Git vero scrivi sempre git commit -m "messaggio".
Due schedeNel menu dei livelli la scheda Principale contiene le prime cinque sezioni, la scheda Remoto le ultime due.

Il modello mentale per i remoti. Le ultime due sezioni lavorano con due repository: il tuo e origin. Il branch o/main è la "memoria" locale di dove si trova main sul remoto.
